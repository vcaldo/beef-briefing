# User Cards API Implementation Guide

## Overview

This document describes the API endpoints for serving user card data to consumers (Telegram Bot and Web Dashboard). Cards are generated by a scheduled cron job and served read-only through these endpoints.

### Consumers
- **Telegram Bot**: Sends cards directly to chat/users
- **Web Dashboard**: Leaderboard displays cards

### Design Principles

| Principle | Implementation |
|-----------|----------------|
| **Group-bound cards** | Each card belongs to ONE specific group (chat_id) |
| **Read-only API** | Cards generated by cron, API only serves data |
| **Authenticated** | All endpoints require Bearer token |
| **Consistent patterns** | Follow existing api-service conventions |
| **JSONB-ready** | Handle nested JSON stats efficiently |

---

## Group-Bound Card Model

**IMPORTANT:** Cards are strictly bound to a single group (chat). A user who participates in multiple groups will have **separate cards for each group**.

```
User 123 in Group A  →  Card for User 123 in Group A
User 123 in Group B  →  Card for User 123 in Group B (different card!)
```

### Why Group-Bound?

| Reason | Explanation |
|--------|-------------|
| **Different personas** | Users behave differently in different groups |
| **Accurate stats** | Sentiment/activity varies by group context |
| **Fair leaderboards** | Compare users within the same group only |
| **Privacy** | Group A members shouldn't see Group B stats |

### Database Constraint

The `ml_user_cards` table enforces this with a composite unique key:

```sql
UNIQUE(user_id, chat_id, week_start)
```

This means:
- Same user can have cards in multiple groups
- Same user can have multiple cards in same group (different weeks)
- But only ONE card per user per group per week

### API Enforcement

All endpoints **require** `chat_id` parameter:
- `GET /api/v1/cards/{user_id}` → requires `?chat_id=X`
- `GET /api/v1/cards` → requires `?chat_id=X`
- `GET /api/v1/cards/{user_id}/history` → requires `?chat_id=X`
- `GET /api/v1/cards/weeks` → requires `?chat_id=X`

Requests without `chat_id` return `400 Bad Request`.

### Cross-Group Access

**Not supported by design.** There is no endpoint to:
- Get all cards for a user across all groups
- Compare a user's stats between groups
- Aggregate stats across multiple groups

If needed in the future, this would require explicit authorization checks to ensure the requester has access to each group.

## Endpoints

### 1. Get Single User Card

```
GET /api/v1/cards/{user_id}?chat_id={chat_id}&week={week_start}
```

**Description:** Retrieve the most recent or specific week's card for a user.

**Parameters:**
| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `user_id` | path | Yes | Telegram user ID |
| `chat_id` | query | Yes | Telegram chat ID |
| `week` | query | No | Week start date (YYYY-MM-DD). Defaults to latest |

### 2. Get All Cards for Chat (Leaderboard)

```
GET /api/v1/cards?chat_id={chat_id}&week={week_start}&sort_by={field}&limit={n}
```

**Description:** Retrieve all user cards for a chat, optionally sorted for leaderboard display.

**Parameters:**
| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `chat_id` | query | Yes | Telegram chat ID |
| `week` | query | No | Week start date (YYYY-MM-DD). Defaults to latest |
| `sort_by` | query | No | Sort field: `mood`, `influence`, `activity`, `reactions` |
| `order` | query | No | Sort order: `asc` or `desc` (default: `desc`) |
| `limit` | query | No | Max results (default: 50, max: 100) |
| `offset` | query | No | Pagination offset (default: 0) |

**Response (200):**

```go
// HandleGetUserCard handles GET /api/v1/cards/{user_id}
func (h *CardHandler) HandleGetUserCard(w http.ResponseWriter, r *http.Request) {
    ctx := r.Context()
    txn := newrelic.FromContext(ctx)

    // Extract path parameter
    vars := mux.Vars(r)
    userIDStr := vars["user_id"]
    userID, err := strconv.ParseInt(userIDStr, 10, 64)
    if err != nil {
        h.respondError(w, "invalid user_id", http.StatusBadRequest)
        return
    }

    // Extract query parameters
    chatIDStr := r.URL.Query().Get("chat_id")
    if chatIDStr == "" {
        h.respondError(w, "chat_id is required", http.StatusBadRequest)
        return
    }
    chatID, err := strconv.ParseInt(chatIDStr, 10, 64)
    if err != nil {
        h.respondError(w, "invalid chat_id", http.StatusBadRequest)
        return
    }

    // Optional week parameter
    var weekStart *time.Time
    weekStr := r.URL.Query().Get("week")
    if weekStr != "" {
        parsed, err := time.Parse("2006-01-02", weekStr)
        if err != nil {
            h.respondError(w, "invalid week format (use YYYY-MM-DD)", http.StatusBadRequest)
            return
        }
        weekStart = &parsed
    }

    if txn != nil {
        txn.AddAttribute("user_id", userID)
        txn.AddAttribute("chat_id", chatID)
    }

    // Get card from service
    card, user, err := h.cardService.GetUserCard(ctx, userID, chatID, weekStart)
    if err != nil {
        if err == services.ErrCardNotFound {
            h.respondError(w, "card not found", http.StatusNotFound)
            return
        }
        slog.Error("failed to get user card", "user_id", userID, "chat_id", chatID, "error", err)
        if txn != nil {
            txn.NoticeError(err)
        }
        h.respondError(w, "internal server error", http.StatusInternalServerError)
        return
    }

    response := map[string]interface{}{
        "card": card,
        "user": user,
    }

    h.respondJSON(w, response, http.StatusOK)
}

// HandleGetChatCards handles GET /api/v1/cards
func (h *CardHandler) HandleGetChatCards(w http.ResponseWriter, r *http.Request) {
    ctx := r.Context()
    txn := newrelic.FromContext(ctx)

    // Parse query parameters
    chatIDStr := r.URL.Query().Get("chat_id")
    if chatIDStr == "" {
        h.respondError(w, "chat_id is required", http.StatusBadRequest)
        return
    }
    chatID, err := strconv.ParseInt(chatIDStr, 10, 64)
    if err != nil {
        h.respondError(w, "invalid chat_id", http.StatusBadRequest)
        return
    }

    // Optional parameters
    var weekStart *time.Time
    if weekStr := r.URL.Query().Get("week"); weekStr != "" {
        parsed, err := time.Parse("2006-01-02", weekStr)
        if err != nil {
            h.respondError(w, "invalid week format", http.StatusBadRequest)
            return
        }
        weekStart = &parsed
    }

    sortBy := r.URL.Query().Get("sort_by")
    if sortBy == "" {
        sortBy = "mood"
    }

    order := r.URL.Query().Get("order")
    if order == "" {
        order = "desc"
    }

    limit := 50
    if limitStr := r.URL.Query().Get("limit"); limitStr != "" {
        if parsed, err := strconv.Atoi(limitStr); err == nil && parsed > 0 && parsed <= 100 {
            limit = parsed
        }
    }

    offset := 0
    if offsetStr := r.URL.Query().Get("offset"); offsetStr != "" {
        if parsed, err := strconv.Atoi(offsetStr); err == nil && parsed >= 0 {
            offset = parsed
        }
    }

    if txn != nil {
        txn.AddAttribute("chat_id", chatID)
        txn.AddAttribute("sort_by", sortBy)
    }

    // Get cards from service
    result, err := h.cardService.GetChatCards(ctx, services.GetChatCardsRequest{
        ChatID:    chatID,
        WeekStart: weekStart,
        SortBy:    sortBy,
        Order:     order,
        Limit:     limit,
        Offset:    offset,
    })
    if err != nil {
        slog.Error("failed to get chat cards", "chat_id", chatID, "error", err)
        if txn != nil {
            txn.NoticeError(err)
        }
        h.respondError(w, "internal server error", http.StatusInternalServerError)
        return
    }

    h.respondJSON(w, result, http.StatusOK)
}
```

```go
// internal/services/card_service.go
package services

import (
    "context"
    "database/sql"
    "errors"
    "fmt"
    "time"

    "github.com/newrelic/go-agent/v3/newrelic"

    "beef-briefing/apps/api-service/internal/repository"

var ErrCardNotFound = errors.New("card not found")

type CardService struct {
    cardRepo *repository.CardRepository
    nrApp    *newrelic.Application
}

func NewCardService(db *sql.DB, nrApp *newrelic.Application) *CardService {
    return &CardService{
        cardRepo: repository.NewCardRepository(db, nrApp),
        nrApp:    nrApp,
    }
}

// Request/Response types
type GetChatCardsRequest struct {
    ChatID    int64
    WeekStart *time.Time
    SortBy    string
    Order     string
    Limit     int
    Offset    int
}

type GetChatCardsResponse struct {
    Cards      []CardWithUser     `json:"cards"`
    Pagination PaginationInfo     `json:"pagination"`
    Metadata   ChatCardsMetadata  `json:"metadata"`
}

type CardWithUser struct {
    UserID           int64                  `json:"user_id"`
    User             UserInfo               `json:"user"`
    WeekStart        string                 `json:"week_start"`
    WeekEnd          string                 `json:"week_end"`
    Stats            map[string]interface{} `json:"stats"`
    Trends           map[string]interface{} `json:"trends,omitempty"`
    MessagesAnalyzed int                    `json:"messages_analyzed"`
    Rank             int                    `json:"rank,omitempty"`
}

type UserInfo struct {
    ID        int64  `json:"id"`
    FirstName string `json:"first_name"`
    LastName  string `json:"last_name,omitempty"`
    Username  string `json:"username,omitempty"`
}

type PaginationInfo struct {
    Total   int  `json:"total"`
    Limit   int  `json:"limit"`
    Offset  int  `json:"offset"`
    HasMore bool `json:"has_more"`
}

type ChatCardsMetadata struct {
    ChatID    int64  `json:"chat_id"`
    WeekStart string `json:"week_start"`
    WeekEnd   string `json:"week_end"`
    SortBy    string `json:"sort_by"`
    Order     string `json:"order"`
}

type UserHistoryResponse struct {
    User    UserInfo         `json:"user"`
    History []CardSummary    `json:"history"`
    Summary UserStatsSummary `json:"summary"`
}

type CardSummary struct {
    WeekStart        string                 `json:"week_start"`
    WeekEnd          string                 `json:"week_end"`
    Stats            map[string]interface{} `json:"stats"`
    Trends           map[string]interface{} `json:"trends,omitempty"`
    MessagesAnalyzed int                    `json:"messages_analyzed"`
}

type UserStatsSummary struct {
    TotalWeeks    int     `json:"total_weeks"`
    AvgMood       float64 `json:"avg_mood"`
    MoodTrend     string  `json:"mood_trend"`
    TotalMessages int     `json:"total_messages"`
}

    Weeks  []WeekInfo `json:"weeks"`

// GetUserCard retrieves a single user's card
func (s *CardService) GetUserCard(
    ctx context.Context,
    userID int64,
    chatID int64,
    weekStart *time.Time,
) (*repository.UserCard, *UserInfo, error) {
    txn := newrelic.FromContext(ctx)
    if txn != nil {
        segment := txn.StartSegment("service:GetUserCard")
        defer segment.End()
    }

    // Get card from repository
    card, err := s.cardRepo.GetUserCard(ctx, userID, chatID, weekStart)
    if err != nil {
        if errors.Is(err, sql.ErrNoRows) {
            return nil, nil, ErrCardNotFound
        }
        return nil, nil, fmt.Errorf("failed to get card: %w", err)
    }

    // Get user info
    user, err := s.cardRepo.GetUserInfo(ctx, userID)
    if err != nil {
        // User info is optional, log but don't fail
        user = &UserInfo{ID: userID, FirstName: "Unknown"}
    }

    return card, user, nil
}

// GetChatCards retrieves all cards for a chat with sorting
func (s *CardService) GetChatCards(
    ctx context.Context,
    req GetChatCardsRequest,
) (*GetChatCardsResponse, error) {
    txn := newrelic.FromContext(ctx)
    if txn != nil {
        segment := txn.StartSegment("service:GetChatCards")
        defer segment.End()
    }

    // Validate sort field
    validSortFields := map[string]string{
        "mood":      "stats->'mood'->>'score'",
        "influence": "stats->'influence'->>'score'",
        "activity":  "stats->'activity'->>'messages'",
        "reactions": "stats->>'reactions_received'",
    }

    sortColumn, ok := validSortFields[req.SortBy]
    if !ok {
        sortColumn = validSortFields["mood"]
        req.SortBy = "mood"
    }

    // Get cards from repository
    cards, total, err := s.cardRepo.GetChatCards(ctx, repository.ChatCardsQuery{
        ChatID:     req.ChatID,
        WeekStart:  req.WeekStart,
        SortColumn: sortColumn,
        SortDesc:   req.Order == "desc",
        Limit:      req.Limit,
        Offset:     req.Offset,
    })
    if err != nil {
        return nil, fmt.Errorf("failed to get chat cards: %w", err)
    }

    // Get week bounds for metadata
    weekStart := ""
    weekEnd := ""
    if len(cards) > 0 {
        weekStart = cards[0].WeekStart
        weekEnd = cards[0].WeekEnd
    }

    return &GetChatCardsResponse{
        Cards: cards,
        Pagination: PaginationInfo{
            Total:   total,
            Limit:   req.Limit,
            Offset:  req.Offset,
            HasMore: req.Offset+len(cards) < total,
        },
        Metadata: ChatCardsMetadata{
            ChatID:    req.ChatID,
            WeekStart: weekStart,
            WeekEnd:   weekEnd,
            SortBy:    req.SortBy,
            Order:     req.Order,
        },
    }, nil
}

// GetUserHistory retrieves a user's card progression
func (s *CardService) GetUserHistory(
    ctx context.Context,
    userID int64,
    chatID int64,
    limit int,
) (*UserHistoryResponse, error) {
    txn := newrelic.FromContext(ctx)
    if txn != nil {
        segment := txn.StartSegment("service:GetUserHistory")
        defer segment.End()
    }

    // Get user info
    user, err := s.cardRepo.GetUserInfo(ctx, userID)
    if err != nil {
        user = &UserInfo{ID: userID, FirstName: "Unknown"}
    }

    // Get history from repository
    history, err := s.cardRepo.GetUserHistory(ctx, userID, chatID, limit)
    if err != nil {
        return nil, fmt.Errorf("failed to get user history: %w", err)
    }

    // Calculate summary
    summary := s.calculateHistorySummary(history)

    return &UserHistoryResponse{
        User:    *user,
        History: history,
        Summary: summary,
    }, nil
}

// GetAvailableWeeks returns weeks with generated cards
func (s *CardService) GetAvailableWeeks(
    ctx context.Context,
    chatID int64,
) (*AvailableWeeksResponse, error) {
    weeks, err := s.cardRepo.GetAvailableWeeks(ctx, chatID)
    if err != nil {
        return nil, fmt.Errorf("failed to get available weeks: %w", err)
    }

    latest := ""
    if len(weeks) > 0 {
        latest = weeks[0].WeekStart
    }

    return &AvailableWeeksResponse{
        Weeks:  weeks,
        Latest: latest,
    }, nil
}

func (s *CardService) calculateHistorySummary(history []CardSummary) UserStatsSummary {
    if len(history) == 0 {
        return UserStatsSummary{}
    }

    var totalMood float64
    var totalMessages int

    for _, h := range history {
        if mood, ok := h.Stats["mood"].(map[string]interface{}); ok {
            if score, ok := mood["score"].(float64); ok {
                totalMood += score
            }
        }
        totalMessages += h.MessagesAnalyzed
    }

    avgMood := totalMood / float64(len(history))

    // Determine mood trend (compare first vs last in history)
    moodTrend := "stable"
    if len(history) >= 2 {
        first := history[len(history)-1] // oldest
        last := history[0]               // newest

        firstMood := getMoodScore(first.Stats)
        lastMood := getMoodScore(last.Stats)

        if lastMood-firstMood > 5 {
            moodTrend = "improving"
        } else if firstMood-lastMood > 5 {
            moodTrend = "declining"
        }
    }

    return UserStatsSummary{
        TotalWeeks:    len(history),
        AvgMood:       avgMood,
        MoodTrend:     moodTrend,
        TotalMessages: totalMessages,
    }
}

func getMoodScore(greenStats map[string]interface{}) float64 {
    if mood, ok := greenStats["mood"].(map[string]interface{}); ok {
        if score, ok := mood["score"].(float64); ok {
            return score
        }
    }
    return 50.0
}
```

```go
// GetUserCard retrieves a single card
func (r *CardRepository) GetUserCard(
    ctx context.Context,
    userID int64,
    chatID int64,
    weekStart *time.Time,
) (*UserCard, error) {
    var query string
    var args []interface{}

    if weekStart != nil {
        query = `
            SELECT id, user_id, chat_id, week_start, week_end,
                   stats_window_start, stats_window_end,
                   stats, trends, daily_breakdown, messages_analyzed,
                   card_version, generated_at
            FROM ml_user_cards
            WHERE user_id = $1 AND chat_id = $2 AND week_start = $3
        `
        args = []interface{}{userID, chatID, weekStart}
    } else {
        query = `
            SELECT id, user_id, chat_id, week_start, week_end,
                   stats_window_start, stats_window_end,
                   stats, trends, daily_breakdown, messages_analyzed,
                   card_version, generated_at
            FROM ml_user_cards
            WHERE user_id = $1 AND chat_id = $2
            ORDER BY week_start DESC
            LIMIT 1
        `
        args = []interface{}{userID, chatID}
    }

    var card UserCard
    var statsJSON, trendsJSON, dailyBreakdownJSON []byte

    err := r.db.QueryRowContext(ctx, query, args...).Scan(
        &card.ID, &card.UserID, &card.ChatID,
        &card.WeekStart, &card.WeekEnd,
        &card.StatsWindowStart, &card.StatsWindowEnd,
        &statsJSON, &trendsJSON, &dailyBreakdownJSON, &card.MessagesAnalyzed,
        &card.CardVersion, &card.GeneratedAt,
    )
    if err != nil {
        return nil, err
    }

    // Parse JSON fields
    json.Unmarshal(statsJSON, &card.Stats)
    json.Unmarshal(trendsJSON, &card.Trends)
    json.Unmarshal(dailyBreakdownJSON, &card.DailyBreakdown)

    return &card, nil
}

// GetChatCards retrieves all cards for a chat
func (r *CardRepository) GetChatCards(
    ctx context.Context,
    q ChatCardsQuery,
) ([]CardWithUser, int, error) {
    // Get week to query
    var weekStart time.Time
    if q.WeekStart != nil {
        weekStart = *q.WeekStart
    } else {
        // Get latest week
        err := r.db.QueryRowContext(ctx, `
            SELECT week_start FROM ml_user_cards
            WHERE chat_id = $1
            ORDER BY week_start DESC LIMIT 1
        `, q.ChatID).Scan(&weekStart)
        if err != nil {
            return nil, 0, fmt.Errorf("failed to get latest week: %w", err)
        }
    }

    // Count total
    var total int
    err := r.db.QueryRowContext(ctx, `
        SELECT COUNT(*) FROM ml_user_cards
        WHERE chat_id = $1 AND week_start = $2
    `, q.ChatID, weekStart).Scan(&total)
    if err != nil {
        return nil, 0, fmt.Errorf("failed to count cards: %w", err)
    }

    // Build order clause
    orderDir := "DESC"
    if !q.SortDesc {
        orderDir = "ASC"
    }

    query := fmt.Sprintf(`
        SELECT c.user_id, c.week_start, c.week_end,
               c.stats, c.trends, c.messages_analyzed,
               u.first_name, COALESCE(u.last_name, ''), COALESCE(u.username, ''),
               ROW_NUMBER() OVER (ORDER BY (%s)::numeric %s) as rank
        FROM ml_user_cards c
        LEFT JOIN users u ON c.user_id = u.id
        WHERE c.chat_id = $1 AND c.week_start = $2
        ORDER BY (%s)::numeric %s
        LIMIT $3 OFFSET $4
    `, q.SortColumn, orderDir, q.SortColumn, orderDir)

    rows, err := r.db.QueryContext(ctx, query, q.ChatID, weekStart, q.Limit, q.Offset)
    if err != nil {
        return nil, 0, fmt.Errorf("failed to query cards: %w", err)
    }
    defer rows.Close()

    var cards []CardWithUser
    for rows.Next() {
        var card CardWithUser
        var statsJSON, trendsJSON []byte

        err := rows.Scan(
            &card.UserID, &card.WeekStart, &card.WeekEnd,
            &statsJSON, &trendsJSON, &card.MessagesAnalyzed,
            &card.User.FirstName, &card.User.LastName, &card.User.Username,
            &card.Rank,
        )
        if err != nil {
            return nil, 0, fmt.Errorf("failed to scan card: %w", err)
        }

        card.User.ID = card.UserID
        json.Unmarshal(statsJSON, &card.Stats)
        json.Unmarshal(trendsJSON, &card.Trends)

        cards = append(cards, card)
    }

    return cards, total, nil
}

// GetUserHistory retrieves a user's card history
func (r *CardRepository) GetUserHistory(
    ctx context.Context,
    userID int64,
    chatID int64,
    limit int,
) ([]CardSummary, error) {
    query := `
        SELECT week_start, week_end, stats, trends, messages_analyzed

// GetAvailableWeeks returns weeks with cards
func (r *CardRepository) GetAvailableWeeks(
    ctx context.Context,
    chatID int64,
) ([]WeekInfo, error) {
    query := `
        SELECT week_start, week_end, COUNT(*) as card_count
        FROM ml_user_cards
        WHERE chat_id = $1
        GROUP BY week_start, week_end
        ORDER BY week_start DESC
    `

    rows, err := r.db.QueryContext(ctx, query, chatID)
    if err != nil {
        return nil, fmt.Errorf("failed to query weeks: %w", err)
    }
    defer rows.Close()

    var weeks []WeekInfo
    for rows.Next() {
        var week WeekInfo
        err := rows.Scan(&week.WeekStart, &week.WeekEnd, &week.CardCount)
        if err != nil {
            return nil, fmt.Errorf("failed to scan week: %w", err)
        }
        weeks = append(weeks, week)
    }

    return weeks, nil
}

// WeekInfo for available weeks
type WeekInfo struct {
    WeekStart string `json:"week_start"`
    WeekEnd   string `json:"week_end"`

}
```

### Telegram Bot Usage

```python
# bot/card_sender.py
import httpx

API_URL = "https://api.example.com"
API_KEY = os.getenv("API_KEY")

async def send_user_card(chat_id: int, user_id: int):
    async with httpx.AsyncClient() as client:
        response = await client.get(
            f"{API_URL}/api/v1/cards/{user_id}",
            params={"chat_id": chat_id},
            headers={"Authorization": f"Bearer {API_KEY}"}
        )

        if response.status_code == 404:
            await bot.send_message(chat_id, "No card available yet!")
            return

        data = response.json()
        card = data["card"]
        user = data["user"]

        # Format card message
        message = format_card_message(card, user)
        await bot.send_message(chat_id, message, parse_mode="HTML")

def format_card_message(card: dict, user: dict) -> str:
    stats = card["stats"]
    trends = card.get("trends", {})

    mood = stats["mood"]
    mood_trend = trends.get("mood", {}).get("direction", "stable")
    trend_emoji = {"up": "↑", "down": "↓", "stable": "→"}.get(mood_trend, "")

    return f"""
<b>📊 {user.get('first_name', 'User')}'s Card</b>
Week: {card['week_start']} - {card['week_end']}

<b>Mood:</b> {mood['label']} ({mood['score']}) {trend_emoji}
<b>Activity:</b> {stats['activity']['messages']} msgs
<b>Reactions:</b> {stats['reactions_received']} received

Based on last 30 days of data.
"""
```
